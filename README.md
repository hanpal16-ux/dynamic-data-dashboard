# My Dynamic Data Dashboard

## Live Demo
[View the website](https://hanpal16-ux.github.io/dynamic-data-dashboard/)

## Project Description
My Dynamic Data Dashboard is a web page that loads live data from
public APIs with the click of a button. It has two cards:
- **Puppies link generator:** shows a random dog picture.
- **User profile:** shows a random user with their photo, name, age,
  country, email, gender, and phone number.

The page updates its content without reloading, using jQuery and
AJAX requests.

This project was developed for the Advanced Frontend – JavaScript &
jQuery course of the Full Stack Software Development program at
Canadian Business College (CBC).

## Technologies
- HTML
- CSS (Flexbox)
- JavaScript
- jQuery 3.7.1
- AJAX (`$.get`)
- [Dog CEO API](https://dog.ceo/dog-api/)
- [Random User API](https://randomuser.me/)

## How to Run
**Option 1:** Visit the live demo link above.

**Option 2:** Run it on your computer:
1. Clone the repository:
   ```bash
   git clone https://github.com/hanpal16-ux/dynamic-data-dashboard.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

Note: an internet connection is required, because jQuery and the
data are loaded from online sources.

## Features
- Fetch and display a random dog picture from the Dog CEO API
- Fetch and display a random user profile from the Random User API
- Updates the page content dynamically without reloading
- Circular profile picture and card-style layout
- Centered, responsive design with Flexbox
